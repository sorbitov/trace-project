# Changelog

All notable changes to PACT are documented here.

## [0.1.0-rc.2] - 2026-07-15

### Added

- Arc Testnet deployment manifest and explorer evidence.
- Live low-value create/claim, create/cancel, and create/refund lifecycle evidence.
- DeFi Track submission package, reviewer documentation, CI, security policy, and public repository templates.

### Changed

- Renamed the public project from HandleLayer/HandlePay to PACT — Programmable Arc Conditional Transfers.

### Security

- Added strict redirect and payment-input validation, sanitized OAuth errors, scoped API views, wallet proof, claim-domain binding, and documented testnet limitations.

## [0.1.0-rc.1] - 2026-07-15

- Initial local release candidate with the Arc escrow MVP, X OAuth integration, PostgreSQL persistence, indexer, and automated tests.
